# Blueprint Workbench 通用化交接

更新：2026-11-19。用户已批准通用化，随后明确其他项目主要使用 UE 5.5，优先验收 5.5。

## 已完成

- 提取独立 0.4.0 Editor 源码插件。通用 Source/Scripts 不包含 Parkour 类型、工程文件名、HUD 内容或 StageB 流程；保留三个公开 API 及默认预览、显式副本保存和备份写回契约。
- CLI 必填 ProjectFile、EngineRoot；附安装、独立宿主生成、构建、集成检查、CLI 检查和源码 ZIP 打包入口。安装／宿主拒绝覆盖既有目标，源码复制与打包排除缓存和构建产物。
- 通用组件创建保留引擎类默认配置；固定碰撞预设不进入核心。refresh_calls 要求显式非空函数列表；不支持的容器明确拒绝。
- 为 UE 5.5 的注释说明字段及元数据 API 差异做局部适配，不增加自定义图节点类；新引擎复制保留原生 FText。
- 维护入口与实际调用见 ARCHITECTURE.md；安装和使用见 ../README.md；版本证据见 COMPATIBILITY.md。

## Parkour 与下一步

Parkour 同时存在未提交的项目插件扩展和玩法资产工作，本任务未覆盖原插件／脚本或写回玩法资产；原项目继续使用其项目版本，尚未切换通用 0.4.0。项目专用 HUD 与 StageB 调用保留在原工程，这是明确的未迁移边界。正式项目迁移应先核对该项目已有插件及专用操作，再安装／构建通用包；不能直接覆盖同名插件。

优先下一步：在需要使用工具的 UE 5.5 项目安装并构建，先 Inspect 和预览该项目的目标图；用户明确选定资产和补丁后再执行具体接线。Material／Niagara 和其他图类型是后续独立扩展。用户已授权 GitHub 提交与推送：独立公共仓库 https://github.com/rainerpj/unreal-blueprint-workbench，主分支 main；只交付通用源码、脚本、文档和精简验证记录，不包含测试宿主、二进制、缓存、原项目资产或完整日志。已按用户要求设为公共仓库，并通过未登录 API 读取核对公开可访问；未创建 GitHub Release。
